# NUSAMETRIK — Indonesia in Numbers

A national statistics site for Indonesia, built for the [make.fun bounty](https://make.fun/bounty/best-national-statistics-site-20261126-0539). Six pages — overview, economy, people, provinces, connectivity, sources — with hand-made SVG charts, a 38-province explorer (search, filter, sort, compare, CSV download), dark/light theme and EN/ID language toggle. Every figure is labelled with its year and source; figures that could not be verified against a published official release as of 26 Nov 2026 are not printed — see `app/sources.html` for the full methodology and the "What we refused to print" table.

## Open or rebuild

Open **app/index.html** from the extracted source tree. It runs directly from disk (file://): no network requests, no external libraries, no CDN, no fonts fetched — all data lives in `app/data.js`.

Run with Node 22.18 or newer. The program has zero runtime dependencies.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`node main.ts` copies `app/` and `screenshots/` to the output directory and writes `dossier.json` there.

## Source tree

| Path | Purpose |
| --- | --- |
| main.ts | Node entrypoint, output builder |
| app/ | Offline site: 6 pages, data.js, style.css, main.js |
| screenshots/ | Real renders of the site itself (desktop + phone) |
| vendor/makefun-frontend.ts | Original make.fun dossier writer, unmodified |
| dossier.json | Canonical vendor output (generated by main.ts) |
